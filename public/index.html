Add a way to reach your assistant

            
Pick one below. Each needs two things: the sign-in details saved under Secrets in the default project, and one line added to the connections file named by BRANCH_INTEGRATIONS. Restart Branch afterwards and it appears in the list above. Whichever you choose, messages from a chat app can never run commands on this computer.

            

              Telegram
              
Create a bot by writing to @BotFather in Telegram. Save the token it gives you as the secret TELEGRAM_BOT_TOKEN, then add {"channels":[{"type":"telegram","tokenSecret":"TELEGRAM_BOT_TOKEN"}]}.

            

            

              Discord
              
Make an application at discord.com/developers, add a bot to it, and turn on Message Content Intent on the bot's page — without it the assistant receives empty messages. Save the bot token as the secret DISCORD_BOT_TOKEN, invite the bot to your server, then add {"channels":[{"type":"discord"}]}. In a server channel it answers when you mention it or reply to it; in a direct message it always answers.

            

            

              Slack
              
Create an app at api.slack.com/apps, turn on Socket Mode, and subscribe to the message.im and app_mention events. Save the bot token (it starts with xoxb-) as SLACK_BOT_TOKEN and the app-level token (xapp-) as SLACK_APP_TOKEN, then add {"channels":[{"type":"slack"}]}. To limit it to certain Slack channels, list their ids in "slackChannels".

            

            

              WhatsApp
              
You need a WhatsApp Business account on Meta's developer site. Save the access token as WHATSAPP_TOKEN, the app secret as WHATSAPP_APP_SECRET, and a word of your own choosing as WHATSAPP_VERIFY_TOKEN, then add {"channels":[{"type":"whatsapp","phoneNumberId":"your number id"}]}. In Meta's settings, point the webhook at <this computer's address>/webhooks/whatsapp/whatsapp and give it the same verify word. WhatsApp only lets the assistant answer within a day of your message; later replies wait in the list below.

            

            

              Email
              
Save the mailbox password as the secret EMAIL_PASSWORD, then add {"channels":[{"type":"email","address":"you@example.com","imap":{"host":"imap.example.com","port":993,"user":"you@example.com"},"smtp":{"host":"smtp.example.com","port":465,"user":"you@example.com"}}]}. The assistant looks for unread mail every minute, answers it, marks it read, and keeps the answer in the same email conversation. It reads and writes plain text only.

      Using your screen and keyboard
      
            
      Branch can look at what is on this computer's screen and work the windows on it — read what a program is showing, press its buttons, type into its boxes. This is switched off, and nothing on this list happens until you switch it on.
      
            
            
      While this is off, Branch says so plainly instead of trying. Turning it off again stops anything that is going on right now.
      
            
      Whenever it is using your screen, a small notice sits on top of everything with a Stop button on it. Press that and Branch lets go at once. Password managers, sign-in boxes and the Windows lock screen are never photographed and never typed into, and it will not type a saved password for you. Every single action is written down in Activity with the name of the window it touched.
      
            
      
              
              
              
            
      
            
      
          
      
          
      
            
      Waiting for your yes

      Websites you stay signed in to
      
            
      Some websites only show your own information once you are signed in. Sign in here once, in a real browser window, and Branch can use that website later without asking you again. You type your password into that window yourself — Branch never sees it, and only the small file the website uses to remember you is kept, scrambled, on this computer.
