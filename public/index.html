Add a way to reach your assistant

            
Pick one below. Each needs two things: the sign-in details saved under Secrets in the default project, and one line added to the connections file named by BRANCH_INTEGRATIONS. Restart Branch afterwards and it appears in the list above. Whichever you choose, messages from a chat app can never run commands on this computer.

            

              Telegram
              
Create a bot by writing to @BotFather in Telegram. Save the token it gives you as the secret TELEGRAM_BOT_TOKEN, then add {"channels":[{"type":"telegram","tokenSecret":"TELEGRAM_BOT_TOKEN"}]}.

            

            

              Discord
              
Make an application at discord.com/developers, add a bot to it, and turn on Message Content Intent on the bot's page — without it the assistant receives empty messages. Save the bot token as the secret DISCORD_BOT_TOKEN, invite the bot to your server, then add {"channels":[{"type":"discord"}]}. In a server channel it answers when you mention it or reply to it; in a direct message it always answers.

            

            

              Slack
              
Create an app at api.slack.com/apps, turn on Socket Mode, and subscribe to the message.im and app_mention events. Save the bot token (it starts with xoxb-) as SLACK_BOT_TOKEN and the app-level token (xapp-) as SLACK_APP_TOKEN, then add {"channels":[{"type":"slack"}]}. To limit it to certain Slack channels, list their ids in "slackChannels".

            

            

              WhatsApp
              
You need a WhatsApp Business account on Meta's developer site. Save the access token as WHATSAPP_TOKEN, the app secret as WHATSAPP_APP_SECRET, and a word of your own choosing as WHATSAPP_VERIFY_TOKEN, then add {"channels":[{"type":"whatsapp","phoneNumberId":"your number id"}]}. In Meta's settings, point the webhook at the address shown on this channel's card above — it ends in a long word made on this computer, so nobody can find it by guessing — and give it the same verify word. WhatsApp only lets the assistant answer within a day of your message; later replies wait in the list below.

            

            

              Email
              
Save the mailbox password as the secret EMAIL_PASSWORD, then add {"channels":[{"type":"email","address":"you@example.com","imap":{"host":"imap.example.com","port":993,"user":"you@example.com"},"smtp":{"host":"smtp.example.com","port":465,"user":"you@example.com"}}]}. The assistant looks for unread mail every minute, answers it, marks it read, and keeps the answer in the same email conversation. It reads and writes plain text only.
