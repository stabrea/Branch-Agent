Updates

Updates come from the Branch Agent releases on GitHub. Each download is checked against its published fingerprint before anything changes.

Projects

A project keeps its own instructions, preferred model and secrets. Switch the active project to change all three at once.

Edit a project below. Choosing a project in the list loads it; save writes it back.

Secrets

Keys and tokens your host commands need. Values are locked away once saved: they are never shown again and the assistant never sees them. A command can only use secrets from the active project.

Channels

Talk to your assistant from Telegram. Each chat keeps its own conversation. People you don't know get a six-digit code the first time they write; approve it here and they're in. In groups, the assistant answers when it is mentioned or replied to.

Messages still to send

Replies and scheduled results are written down before they go out. If a chat app is unreachable they wait here, go out in order once it is back, and stop after five failed tries until you press Try again.

To connect Telegram: create a bot with @BotFather, save its token as the secret TELEGRAM_BOT_TOKEN in the default project, and add {"channels":[{"type":"telegram","tokenSecret":"TELEGRAM_BOT_TOKEN"}]} to the integrations file named by BRANCH_INTEGRATIONS. Restart Branch afterwards. Channel tasks cannot run host commands.

Hooks

Small commands that run when something happens, for example when a task finishes or a file changes. A hook that keeps failing is switched off by itself so it cannot slow your tasks down.

Health check

Checks the pieces this app depends on and tells you what to do if one is not right.

Backup

Save everything this app knows (conversations, memory, skills, schedules, settings) to one file. Secrets stay on this device and are not included. To bring a backup back, install Branch Agent fresh and run branch restore <file>.

Workspace snapshots

Keep a copy of every file in your workspace and put them all back later. Each change the assistant makes to a file can also be undone one at a time from Activity.

Models

Choose which model answers by default. Each conversation can pick its own. If a model is unavailable, Branch tries the next one on your list and rests the failed one for a while.
