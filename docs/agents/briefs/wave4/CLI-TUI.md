# Wave 4 task: a terminal experience worth using

Rules: docs/agents/briefs/wave1/BUILD.md. Branch: wave4/cli-tui from the local branch wave2/integration. Theme: cli-and-tui (#72, 23 pieces). Terminal only; no web UI changes.

Read: src/cli.ts, src/terminal*.ts (streaming terminal chat), src/openai-compat.ts, src/streams.ts, tests/cli.test.mjs, tests/terminal.test.mjs, docs/configuration.md CLI section.

Build (Node built-ins only: readline, process.stdout with ANSI, no ink/blessed):
1. `branch chat` becomes a full-screen-friendly TUI without a dependency: a status line (model, tokens, cost this session, approval preset), streaming answers with word wrap, tool steps as compact one-line rows that expand with a key, slash commands (`/model`, `/preset`, `/memory`, `/skills`, `/plan`, `/verify`, `/dry-run`, `/attach <file>`, `/history`, `/export`, `/help`), history navigation with the up arrow, multi-line input with Alt+Enter, Ctrl+C interrupts the current run (not the app) and Ctrl+D exits. Falls back to the plain streaming mode when stdout is not a TTY.
2. Approvals in the terminal: when a run pauses for a yes, the TUI shows the question with the exact command/path and takes y / n / a (always) / s (session), reusing the policy routes.
3. `branch run` gains `--json` (event stream as JSON Lines), `--attach`, `--plan`, `--verify`, `--dry-run`, `--preset`, `--budget`, `--timeout`, and exit codes (0 ok, 2 needs input, 3 failed, 4 budget) documented for scripts; `branch status` shows running tasks and the health summary; `branch logs <runId>` prints the timeline; `branch approve <id> yes|no`.
4. Shell completion scripts for PowerShell and bash generated by `branch completion <shell>`.
5. Windows Terminal niceties: sets the window title to the current task, uses OSC 9;4 progress where supported, avoids control characters when `NO_COLOR` or a non-VT terminal is detected.

Tests (tests/cli-tui.test.mjs): drive the TUI through a pseudo-TTY substitute (spawn with `FORCE_TTY=1` and a fake columns/rows env; assert on ANSI-stripped output): slash commands, interrupt, approval y/n path, `run --json` event lines and exit codes, completion script generation, NO_COLOR output has no escape codes.

Acceptance: C1 TUI works with no dependency and degrades to plain mode; C2 approvals in terminal proven; C3 exit codes and JSON proven; C4 completion scripts generated; C5 docs section; C6 existing cli/terminal tests green. Report the ids you consider done.
