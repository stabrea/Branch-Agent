Per-run connection lifecycle (connection-lifecycle): MCP client connections are opened when a run first needs a server and closed when the run ends (or kept warm for N minutes, configurable), with a cap on concurrent servers, health shown per server in Settings -> Connections, and reconnect with backoff; per-user (profile) MCP settings honoured where household profiles exist.

Built-in browser MCP server (A2082) and MCP apps proxy (mcp-apps): expose the browser tools over MCP behind the same approval rules; an "MCP app" (a server that returns HTML UI resources) can be shown in the context pane in a sandboxed iframe with no network except the app's own resource reads; refuse scripts that try to escape (CSP `sandbox`).
