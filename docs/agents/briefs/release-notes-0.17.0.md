## What changed in 0.17.0

**It shows you the plan first, if you want it to.** A new switch on the conversation: "just do it", which is what Branch has always done and is still the default, or "show me the plan first". In plan mode you get numbered steps in plain words, each one naming what it will touch and whether it changes anything, and nothing that changes anything happens until you say yes. Approving is one press. You can reword a step and approve that instead, or send the whole plan back with a reason, which goes to the model so the next attempt answers it. If a step turns out to need something the plan never mentioned, Branch stops and tells you what the difference is rather than quietly doing it. You also choose how far it may go before checking back: every step, only the steps that change something, or not until the end.

**A box to run things in, and other computers.** An approval rule could already say how tightly a program is held. Now, where your computer has Docker, WSL or Windows Sandbox, that is a real box rather than just a limit on memory and processor. A backend you do not have refuses in plain words and names what to install. Branch can also work on another computer you already sign in to over SSH: host names from your own configuration only, an unknown host refused outright, an allowlist of what may run there, and the approval card naming which machine. A new Firewall card reads as sentences rather than settings, so you can see what can reach out. Scripts are checked for forbidden calls before anything starts, file changes get a checkpoint you can undo, and conversations can be pruned on a schedule that exports before it deletes.

**It writes documents, not just reads them.** Word, Excel and PowerPoint files, made on this computer with no extra software. Headings, lists and tables in a document; sheets with real numbers, money and percentage formats and formulas that still recalculate; slides with bullets and pictures. Each file was opened in the real Word, Excel and PowerPoint to check. Knowledge bases gained summaries with citations, renaming, merging, splitting and export, a light map of how things connect, and pictures described once and then searchable.

**It notices things, and asks before remembering them.** Branch now learns from what actually happens rather than only from what you type: a file you keep coming back to, a name that keeps recurring, a correction you made halfway through. Each one arrives as a suggestion with the reason it was noticed, in plain words. Nothing is ever remembered without you, and turning a suggestion down stops that same thing being offered again. No model is called to do any of it and nothing leaves the computer.

**Flows that really run.** Flows are now a proper graph: branches that choose a path from the last result, loops with a limit you set, steps that fan out over a list and gather again, and a flow inside a flow. A bad flow is refused before it starts, naming the box at fault. The state is written down after every box, so a flow that stops at the ninth step carries on from there rather than starting again. A box left half-run when the app stopped is asked about rather than repeated: Branch tells you which box it was and you say whether to do it again or carry on past it. Only boxes that merely make a choice or join a list together are redone without asking, because doing those again costs nothing and gives the same answer. A saved flow can be used as a tool.

**Long jobs that survive being interrupted.** A conversation comes back after a restart with its model, its project, its open toolboxes and the permissions you had granted, and says plainly if anything could not be restored. A restart can never lengthen a permission. A shell can be kept open across several tasks, held to the same rules and limits as any other command and closed with the app. The whole assistant runs with no window at all for a scripted job. And a repeating schedule that failed once used to stop for good without saying so; it now moves on to its next turn, counts the failures and pauses after three, saying why.

**Under the hood.** Short-lived keys that expire and can be revoked, secrets fetched from your own password manager instead of copied, traces and logs that can be exported on your terms, and the command line documented and installable as a package. Opening a large toolbox now costs a bounded amount however many tools it holds.

**Install**
Download `Branch-Agent-windows-x64.zip`, unzip it, and run `Branch Agent.exe`. From 0.7.3 onward the in-app update is silent. The checksum is in `Branch-Agent-windows-x64.zip.sha256`.
